# Sign in with Grok (Beta) and full Agentic mode

Use an eligible Grok subscription (plans that include Grok CLI / API access) for chat and full Agentic mode in the editor, without buying separate xAI API credits first. Sign-in is Beta: it uses the same public Grok CLI OAuth flow and may change. Your subscription quota applies. You can top up credits or turn on auto-purchase in your xAI account if you need more. An xAI API key remains a supported alternative and fallback.

Chat, Collections, and Agentic mode (official Grok Build CLI) run in the editor. Collections still need an xAI API key. They are off when using only Grok sign-in.

## Try it

1. Install from [Marketplace](https://plugins.jetbrains.com/plugin/29268-intellego-grok-ai-assistant).
2. Open **Grok Assistant**. Welcome is the cockpit.
3. In Settings, **Sign in with Grok (Beta)**, or paste an xAI API key and **Test connection**. You can also **Request Demo Access**.
4. Chat is the taste. **Premium** (14-day trial) is Agentic, Collections, and Radar.

Demo Access is a limited self-hosted model, not Grok. No JCEF required (4.6.5+). Android Studio works on the default runtime.

## File an issue

Use **[Issues](https://github.com/diligiteiust/intellego-plugin/issues)** on this repo. Include:

- IDE name and version (Help → About)
- Plugin version (Welcome tab or Settings → Plugins)
- What the **Welcome** status rows say (API key, Premium, grok CLI) — copy the text, not a screenshot of secrets
- What you did, what you expected, what happened

Do **not** paste xAI API keys, management keys, license keys, or demo tokens.
